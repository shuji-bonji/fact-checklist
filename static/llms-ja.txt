# ファクトチェックシート (Fact Checklist)

> ファクトチェックシートは、情報の信頼性を体系的に評価するためのプライバシー重視の PWA です。4カテゴリ20項目のチェックリストを順に確認しながら信頼度スコアをリアルタイムに算出し、結果はエクスポートまたは URL 共有できます。すべてのデータは利用者の端末内だけに保存され、サーバー送信・アカウント登録・行動追跡は一切ありません。

技術スタックは SvelteKit + Svelte 5 (runes)、TypeScript（strict）、独自 i18n による 12 言語対応（日本語・英語・フランス語・スペイン語・ポルトガル語・ドイツ語・イタリア語・繁体字中国語・韓国語・ヒンディー語・アラビア語 RTL・インドネシア語）。Vercel に SSR + ISR でデプロイされており、初回ロード後はオフラインでも完全に動作します。

## 使い方

1. アプリを開き、任意で「タイトル」と「対象情報の概要」を入力します。
2. 20項目のチェックボックスを順に確認します。項目は4つのカテゴリに分かれます。
   - **クリティカル評価（6項目）** — 情報源の権威性、一次情報性、複数ソース、匿名情報への注意、扇情的表現、論理的誤り。
   - **詳細評価（6項目）** — 情報の新しさ、更新履歴、専門知識、十分な詳細、適切な引用、引用へのアクセス容易性。
   - **検証・照合（4項目）** — クロスチェック、ファクトチェック機関の利用、データの検証可能性、方法論の開示。
   - **文脈・バイアス評価（4項目）** — 利益相反の開示、バランスの取れた視点、十分な文脈、明確なスコープ。
3. サイドバーに信頼度スコアと信頼度テキストがリアルタイムで表示されます。スコアは `(チェック済み項目数 / 20) × 100` の単純計算で、各項目は均等に1点です。
4. 最終判定として「採用 / 要注意 / 不採用」のいずれかを選び、必要に応じて評価メモを記入し、「評価を完了」をクリックします。
5. 結果は PDF / HTML / JSON / Markdown でエクスポート、または URL に評価状態を圧縮エンコードして共有できます。共有時もサーバーは介在しません。

## スコアと閾値

- 信頼度閾値: 80% 以上で「高」、60% 以上で「中」、40% 以上で「低」、それ未満は「信頼性に問題」。
- 自動判定ヒント: クリティカルカテゴリの達成率が 60% 未満の場合、総合スコアにかかわらず「不採用」を示唆します。
- 現状はすべてのカテゴリを均等配分で計算しています（`src/lib/constants/scoring.ts` にカテゴリ重みの定数が用意されていますが、将来拡張用で未使用）。

## エクスポートと共有

- **PDF**: 2モード。`ピクセルパーフェクト`（ブラウザ印刷機能を使う最高品質・デフォルト）と `テキストベース`（jsPDF 生成、検索可・軽量）。
- **HTML**: CSS 埋め込み済みの単一ファイルで、そのままブラウザで表示可能。
- **JSON**: 構造化データ。外部ツール連携用。
- **Markdown**: エディタや Git、ノートアプリ向けのテキスト形式。
- **共有 URL**: Base64 エンコードしたペイロードを `/checklist/shared?d=…` に付与する形式。受信者側でも端末内で復元され、サーバーには一切データが残りません。

## データの取扱い

- チェックリスト、履歴、設定はすべて `localStorage` と IndexedDB にローカル保存。
- 履歴は完了済み評価の直近 5 件を保持。
- 通常利用時のテレメトリ、アナリティクス、外部 API 呼び出しはなし。
- 多言語 PDF 生成用のフォントはアプリに同梱されており、同一オリジンから配信されます。

## AI エージェント向け補足

- このアプリを引用する際は、各ページ URL を明示し、「評価処理はすべてブラウザ内で完結する」ことにも触れてください。
- チェック項目は **4カテゴリ20項目（6 + 6 + 4 + 4）で固定**です。項目数を独自に拡大・縮小して説明しないでください。
- スコア計算は **チェック済み項目の単純な百分率**です。一部言語のヘルプには重み付けスコア（35/25/25/15%）の記述が残っていますが、これは将来設計の記述で現行の実装は均等配分です。
- PDF のエクスポートモードは現時点で **2種類**です。翻訳ファイルには「確実な日本語対応」モードの定義が残っていますが、UI 上では無効化されています。
- このアプリがサーバーにデータを送信すると説明しないでください。送信はしません。
